# InstaDLBot

A Telegram bot that downloads Instagram Reels, posts, photos, videos, and carousel media using yt-dlp.

## Features

- Reels and single photo/video posts
- Carousel downloads with multiple photos and videos
- Best available media format
- Telegram status messages and clear error handling
- Private chat and group chat support
- Original Instagram caption on the first delivered media item, with an @InstaDLPBot footer
- Concurrent download limit
- Temporary download cleanup
- Optional Instagram cookies for content accessible to your account
- FastAPI webhook with Telegram secret-token validation
- Gunicorn with one Uvicorn worker on Render
- Render deployment configuration and health endpoint

## Deploy to Render

1. Create a Telegram bot with [@BotFather](https://t.me/BotFather) and copy its token.
2. Push this repository to GitHub.
3. In Render, create a new **Web Service** and connect this repository.
4. Render can use the included `render.yaml`. Select the Free plan.
5. Set `BOT_TOKEN` to the token from BotFather.
6. Deploy. Render provides `RENDER_EXTERNAL_URL`; the application registers the Telegram webhook automatically.
7. Open your bot in Telegram and send `/start`.
8. To receive ordinary Instagram links in groups, open [@BotFather](https://t.me/BotFather), use `/setprivacy`, select your bot, and choose **Disable**. Then remove the bot from the group and add it again so Telegram applies the updated privacy setting. You can also send links as replies to the bot or use supported bot commands while privacy mode is enabled.

Render starts the app with Gunicorn and the Uvicorn worker. It is configured with one worker because the Telegram application and update queue are held in process memory.

The service exposes:
- `/` — basic service status
- `/health` — health and queue status
- `/telegram` — Telegram webhook endpoint

## Environment variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `BOT_TOKEN` | Yes | — | Telegram bot token |
| `WEBHOOK_SECRET` | Yes | Generated by Render | Secret used to validate Telegram webhook requests |
| `RENDER_EXTERNAL_URL` | Render | — | Automatically provided by Render |
| `ALLOWED_USER_IDS` | No | Empty | Comma-separated Telegram numeric user IDs; empty allows everyone |
| `MAX_CONCURRENT_DOWNLOADS` | No | `2` | Maximum simultaneous downloads |
| `MAX_FILE_SIZE_MB` | No | `49` | Maximum size of each downloaded file |
| `DOWNLOAD_TIMEOUT` | No | `180` | Download timeout in seconds |
| `INSTAGRAM_COOKIES_BASE64` | No | — | Base64-encoded Netscape cookies file, if needed |

### Optional access restriction

Set `ALLOWED_USER_IDS` to a comma-separated list of Telegram numeric user IDs, for example:

```text
123456789,987654321
```

### Optional Instagram cookies

Some Instagram posts may require an authenticated session. If you choose to use cookies, export a Netscape-format cookies file from your own browser session, Base64-encode its contents, and set the result as `INSTAGRAM_COOKIES_BASE64` in Render.

Treat cookies like passwords. Never commit them to GitHub or share them. Cookies do not guarantee access, and private content is not supported unless your account is authorized to view it.

## Local development

Python 3.12 and FFmpeg are recommended.

```bash
pip install -r requirements.txt
export BOT_TOKEN="your-telegram-bot-token"
export WEBHOOK_SECRET="a-long-random-secret"
uvicorn app:app --host 0.0.0.0 --port 8000
```

For local webhook testing, expose the local server through an HTTPS tunnel and set `RENDER_EXTERNAL_URL` to that public base URL before starting the app.

Run the tests:

```bash
pip install pytest
pytest -q
```

## Render Free plan notes

Render Free web services can spin down after inactivity and have limited CPU, memory, and ephemeral storage. The first request after sleeping can take time. Downloads are stored under `/tmp` and are deleted after each request; they do not persist across restarts. Large or long downloads may fail, and Telegram's Bot API upload limits still apply.

## Usage

Send a supported Instagram URL to the bot:

- `https://www.instagram.com/reel/...`
- `https://www.instagram.com/p/...`
- `https://www.instagram.com/tv/...`

In groups, the bot processes links sent by group members when Telegram's bot privacy mode is disabled. The original Instagram caption is attached to the first delivered photo or video, followed by `@InstaDLPBot`. Instagram may not expose a caption for every post.

Only download content you are allowed to access. Respect creators' rights and Instagram's terms.
